## Reporting Issues & Feature Requests

Found a bug, have a suggestion, or want to propose a new language feature?

Please create a work item on GitLab:

<https://gitlab.com/ninthcircle/lambda-discipline/-/work_items>

When reporting a bug, please include:

* Your operating system and compiler
* The Lambda Discipline version (or commit hash)
* Steps to reproduce the issue
* The expected and actual behavior
* Any relevant source code or error messages

Feature requests, language proposals, editor integrations, documentation improvements, and build system enhancements are all welcome.
