## Reporting Issues & Feature Requests

Found a bug, have a suggestion, or want to propose a new language feature? Please [open an issue on GitHub](https://github.com/lambda-discipline/lambda-discipline/issues).

Before opening an issue, please:

* Search the existing issues to make sure the problem or request has not already been reported.
* Review related issues for existing discussions, workarounds, or possible solutions.
* Check the documentation and other relevant project resources where appropriate.
* Provide enough context for others to understand and reproduce the issue or evaluate the proposal.

When reporting a bug, please include:

* Your operating system and compiler/toolchain.
* The Lambda Discipline version or commit hash.
* Clear steps to reproduce the issue.
* The expected behavior and the actual behavior.
* A minimal reproducible example, where possible.
* Relevant source code, error messages, logs, or build output.
* Any workarounds or possible solutions you have already identified.

For feature requests and language proposals, please explain the motivation, intended behavior, and any relevant use cases or prior discussion.

Feature requests, language proposals, editor integrations, documentation improvements, and build system enhancements are all welcome.
